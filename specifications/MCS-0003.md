# MCS-0003

## Operational State Machine Specification

### Version 1.0 – State Transitions

---

# 1. Introduction
This document defines the formal state machine governing `OperationalObjects`. It establishes valid states, transitions, and the constraints required to move an object through its lifecycle.

# 2. The Universal State Machine

Every operational entity flows through a standardized macro-lifecycle:

`Draft` → `Pending` → `Approved` → `In Progress` → `Completed` → `Archived`

# 3. State Definitions & Restrictions

## 3.1 Draft
- **Definition**: The object is being conceptualized.
- **Rules**: Mutable. Does not trigger downstream policies.

## 3.2 Pending
- **Definition**: The object is awaiting formal governance approval to proceed.
- **Rules**: Requires at least one outgoing relation of type `REQUESTS_APPROVAL`. Modification resets the state back to `Draft`.

## 3.3 Approved
- **Definition**: Governance policies have passed. The object is cleared for execution.
- **Rules**: Must possess an incoming relation of type `APPROVES`. Cannot be transitioned to `In Progress` if blocking dependencies exist.

## 3.4 In Progress
- **Definition**: The entity is actively being worked on.
- **Rules**: Must have an assigned `Owner`. Time tracking begins.

## 3.5 Completed
- **Definition**: The operational objective has been met.
- **Rules**: 
  - **CRITICAL**: Cannot enter `Completed` without at least one incoming relation of type `PROVES` (Evidence).
  - Triggers the `Knowledge Extraction` cycle.

## 3.6 Archived
- **Definition**: The object has reached the end of its operational relevance but is preserved for institutional memory.
- **Rules**: Read-only. Never deleted.

# 4. State Transitions

| From | To | Required Action | Required Relation / Evidence |
|------|----|-----------------|------------------------------|
| Draft | Pending | Submit for Review | None |
| Pending | Approved | Governance Approval | `APPROVES` |
| Pending | Draft | Rejection | `REJECTS` |
| Approved | In Progress | Start Execution | Must not have active `BLOCKS` |
| In Progress | Completed | Finalize Work | `PROVES` (Evidence) |
| Completed | Archived | Time Decay / Manual | None |
