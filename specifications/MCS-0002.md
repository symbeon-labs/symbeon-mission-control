# MCS-0002

## Computational Ontology Specification

### Version 1.0 – Foundational Ontology

---

# 1. Introduction
This document defines the formal vocabulary and structural hierarchy of the Symbeon Mission Control ecosystem. It classifies all computational entities that describe, explain, and govern organizational reality.

# 2. Entity Ontology

## 2.1 Base Entity
- **Entity**: The fundamental unit of the system.
  - **OperationalObject**: The core computable unit representing organizational state.
    - **Task**: An actionable unit of work.
    - **Decision**: A formal organizational choice.
    - **Evidence**: Verifiable proof of action or state.
    - **Knowledge**: Reusable institutional learning extracted from operations.
    - **Policy**: An executable governance rule.
    - **Violation**: An active breach of a policy.
    - **Meeting**: A temporal convergence of stakeholders.
    - **Release**: A bounded delivery of value.

# 3. Relation Ontology

## 3.1 Relational Edges
Relations explain the operational reality by connecting Entities.

- **Relation**: The directed, typed edge linking OperationalObjects.
  - **Dependency**: Temporal or operational blocking (e.g., `BLOCKS`, `DEPENDS_ON`).
  - **Governance**: Policy and compliance enforcement (e.g., `APPROVES`, `VALIDATES`).
  - **Evidence**: Proof of existence and completion (e.g., `PROVES`, `ATTACHED_TO`).
  - **Knowledge**: Epistemic derivation (e.g., `LEARNS_FROM`, `DERIVES_FROM`).
  - **Structural**: Hierarchical containment (e.g., `BELONGS_TO`, `CONTAINS`).
  - **Delivery**: Release and deployment mapping (e.g., `DELIVERS`, `IMPLEMENTS`).
  - **Influence**: Impact without explicit blocking (e.g., `INFLUENCES`, `AFFECTS`).

# 4. Event Ontology

## 4.1 Temporal Actions
Events represent discrete mutations in the graph over time.

- **Event**: An immutable historical record.
  - **Object Event**: `CREATED`, `UPDATED`, `DELETED`, `STATUS_CHANGED`.
  - **Policy Event**: `EVALUATED`, `PASSED`, `FAILED`, `BYPASSED`.
  - **Evidence Event**: `ATTACHED`, `VERIFIED`, `REJECTED`.
  - **Knowledge Event**: `EXTRACTED`, `APPLIED`, `OBSOLETED`.
  - **Governance Event**: `SCORE_CHANGED`, `MATURITY_INCREASED`, `AUDIT_TRIGGERED`.
