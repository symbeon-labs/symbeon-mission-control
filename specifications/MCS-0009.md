# MCS-0009

## Agent Specification

### Version 1.0 – Agent Governance & Boundaries

---

# 1. Purpose & Scope
Defines the strict operational boundaries, identity, lifecycle, permissions, and accountability of AI Agents interacting with Mission Control.

# 2. The Agent Boundaries (The Non-Negotiables)

1. **Agents Observe & Propose**: Agents may read the graph, simulate policies, and draft operational objects/relations.
2. **Humans Govern**: No agent may approve high-severity decisions or bypass governance policies without explicit human approval.
3. **Agent Actions Require Evidence**: Every change made by an agent must generate an `AI Generated Evidence` object containing its reasoning trace.
4. **Immutability of Audit**: Agent actions are logged in the `AuditEngine` with immutable agent signatures.

# 3. Agent Lifecycle & Trust Levels

- **Level 0 (Observer)**: Read-only access to graph analytics.
- **Level 1 (Assistant)**: Can draft tasks, documents, and suggest relations.
- **Level 2 (Operator)**: Can execute routine tasks and attach automated evidence.
- **Level 3 (Autonomous Agent)**: Bound by strict policy sandboxes; can execute pre-approved policy actions.
